# 美术方向

## 目标体验

像把一盒高饱和玩具棋盘倒在桌上：活泼、清楚、略带失控，但在手机屏幕上仍能一眼认出位置、当前回合和得分。

## 视觉支柱

1. **原版纸板赛道**：必须直接使用项目方提供的 `MILD MILE` / `WILD WILDS` 实拍地图，经机械透视校正后作为桌面贴图；图案、文字、色块、纸板中缝与特殊格不得重绘。
2. **粗轮廓玩具**：卡片、按钮、棋子都使用黑色硬边与偏移阴影。
3. **原画纸板立牌**：从项目方提供的规则书卡面提取 36 名角色原画，统一放入玩家色厚边框、底座和阴影中，形成桌游式 3D 立绘。
4. **桌面仪式感**：秘密锁定后逐张翻牌，骰子在赛道中央落定，棋子再逐格跳步；规则结果始终先于装饰动画被看见。
5. **单一行动焦点**：顶部玩家顺序、完整角色卡、玩家头像、棋盘光圈与能力播报必须指向同一名正在结算的角色；直到移动及联动播完才切给下一位。

## 规则

- 背景：`#17131c`；纸张：`#fff8e8`。
- 主强调：`#ff4b2b`；奖励：`#ffd52a`；联机/信息：`#55d5ee`；角色强调：`#f04cab`。
- 字体使用 Noto Sans SC 900/700/500；关键信息不只依靠颜色表达。
- Three.js 使用正交等距镜头、低面数立牌、共享材质语言和柔和单主光；竖屏自动将赛道转为纵向构图。
- Three.js 只能为原版跑道增加纸板厚度、清漆反光、桌面阴影和棋子，不得覆盖或重新解释原图视觉。
- 每个立牌上方使用玩家色名牌标明归属；当前行动者另有箭头与发光边框，同格角色扇形展开。
- 棋子比例向实体纸板立牌靠拢：窄身原画、粗黑边、玩家色底座；不得为了模拟模型而重新绘制角色。
- 2–4 名角色同格时使用共享底盘与“同格 ×N”标记，按 2 人横排、3 人三角、4 人 2×2 展开；不得把完整卡框叠在同一位置。
- 当前行动角色在底部显示原画、玩家头像、玩家名、完整有效能力文本和所在格；复制能力必须同时注明能力来源。
- 竖屏全览时原版棋盘至少占约三分之二屏宽；棋子等待确认、移动或触发能力时，镜头把相关棋子移到上下操作栏之间的无遮挡区域。本人棋子名牌明确增加“你 / YOU”。
- 手机比赛常驻层只保留局数与行动者、紧凑角色能力栏和一个主操作区；准备状态、普通日志与发现式操作说明不得再以独立浮层重复覆盖棋盘。点按棋子仍可查看未截断的完整角色卡，但比赛界面不主动说明点按或长按手势。
- 默认保持全局镜头；逐格移动、绊倒与能力结算时平滑聚焦到相关棋子，结束后回到全局，运镜不得遮挡规则文字。
- 点按棋子打开完整角色信息；长按跑道格打开格子效果说明。两者作为可发现的进阶操作，不显示常驻教学文案；弹层均提供明确关闭方式，且不改变规则状态。
- 骰子忠于实物：单颗骰子使用统一的柔和糖果色塑料外壳、夸张圆角和高光倒角；六面分别使用红、蓝、黄、紫、绿、粉的粗数字与黑色描边，不使用常规点数。点按和上甩共用同一段不超过约 1 秒的投掷演出，上甩方向会影响初始飞入方向与旋转。
- 当规则预测本次投骰至少存在一个可冲线点数时，进入约 2.35 秒的“冲线节目效果”：漫画速度线、呼吸式聚光、延迟揭晓数字、冲线/差一点结果字样与轻量期待音效。骰子材质、镜头和地图不改变；只有结算节奏升级。
- 冲线音效使用低音双拍、上升玩具音阶和成功/落空收束音，不加载外部音频资源；设置中必须提供本机音效开关。
- 角色能力、跑道格和冲线事件逐条展示约 0.7 秒，并在棋盘上同步高亮来源角色；连锁队列应显示剩余条数，但最长只保留最近 6 条，避免拖慢比赛。
- 选角时先显示所有玩家的“挑选中 / 已选 / 已锁定”状态，再显示自己的选择与手牌；卡片在约 0.26 秒的确认动画后才离场。
- 全员揭晓时每张角色默认停留 7 秒，任何查看者可点按本机立即继续；设置开启“自动跳过辅助操作”后使用约 1.1 秒快速展示。
- 玩家掷骰并完成规则结算后，默认由该玩家点按自己的棋子开始逐格移动演出；绊倒角色轮到时由玩家点按“扶起来”确认跳过主移动。上述无分支操作可在设置中自动跳过。
- 手机操作集中在底部拇指热区，按钮不小于约 44px；赛事日志在窄屏改为可关闭抽屉。
- 移动端像素比限制为 1.5；无重型后处理，静态观众灯点不参与规则反馈，阴影贴图 1024。
- 支持 `prefers-reduced-motion`，界面动画不承载规则信息。

## 禁止项

- 不重绘、变形或生成式篡改项目方提供的角色原画；只做一致的卡面裁切与显示优化。
- 不用程序色块或生成图替代原版跑道；若原图清晰度不足，应优先请求更高分辨率扫描件，而不是臆造细节。
- 不加入写实材质、高频纹理、霓虹科幻 UI 或影响读数的镜头抖动。
- 不用颜色单独表示“轮到谁”或“是否连接”。
- 不让普通投骰变慢，也不在没有真实冲线可能时滥用悬念演出。
