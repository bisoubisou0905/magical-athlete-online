# 美术方向

## 目标体验

像把一盒高饱和玩具棋盘倒在桌上：活泼、清楚、略带失控，但在手机屏幕上仍能一眼认出位置、当前回合和得分。

## 视觉支柱

1. **糖果赛道**：红、黄、青、绿、粉、紫循环，深色桌面提供强对比。
2. **粗轮廓玩具**：卡片、按钮、棋子都使用黑色硬边与偏移阴影。
3. **原画纸板立牌**：从项目方提供的规则书卡面提取 36 名角色原画，统一放入玩家色厚边框、底座和阴影中，形成桌游式 3D 立绘。

## 规则

- 背景：`#17131c`；纸张：`#fff8e8`。
- 主强调：`#ff4b2b`；奖励：`#ffd52a`；联机/信息：`#55d5ee`；角色强调：`#f04cab`。
- 字体使用 Noto Sans SC 900/700/500；关键信息不只依靠颜色表达。
- Three.js 使用正交等距镜头、低面数立牌、共享材质语言和柔和单主光；竖屏自动将赛道转为纵向构图。
- 移动端像素比限制为 1.5；无重型后处理，静态观众灯点不参与规则反馈，阴影贴图 1024。
- 支持 `prefers-reduced-motion`，界面动画不承载规则信息。

## 禁止项

- 不重绘、变形或生成式篡改项目方提供的角色原画；只做一致的卡面裁切与显示优化。
- 不加入写实材质、高频纹理、霓虹科幻 UI 或影响读数的镜头抖动。
- 不用颜色单独表示“轮到谁”或“是否连接”。
